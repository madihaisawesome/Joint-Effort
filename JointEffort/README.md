# JointEffort (frontend)

React + Vite UI for Joint Effort.

## Run

From the repo root, see the main [README](../README.md). Short version:

```bash
# terminal 1 — backend
cd ../backend && npm start

# terminal 2 — this app
npm install
npm run dev
```

Open http://localhost:5173 and use **Exercises → Judge Demo** for the fast judging path.
